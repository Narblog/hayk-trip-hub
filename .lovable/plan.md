# iPhone-ում կացարանի էջի կայունացում

## Կատարում
- iPhone չափով վերարտադրել էջի լայնության փոփոխությունն ու հորիզոնական շարժը։
- Ամրացնել կացարանի լուսանկարների, վերնագրի, ամրագրման հատվածի և բացվող պատուհանների լայնությունները փոքր էկրանների համար։
- Կանխել iOS-ում input focus-ի և երկար տեքստերի պատճառով էջի լայնացման կամ zoom-ի փոփոխությունը։
- Ստուգել իրական կացարանի էջը iPhone չափով՝ սկզբնական բեռնումից հետո և ամրագրման դաշտերի հետ աշխատելիս։

## Տեխնիկական մանրամասներ
- Պահպանել ներկայիս desktop դասավորությունն ու ամրագրման գործողությունները։
- Օգտագործել կայքի առկա responsive չափերը և semantic ոճերը։
